# 📊 Path: Data & Business Analytics
### Turning Raw Numbers Into Clear Business Decisions (Without a Math Degree)

**Barrier to Entry:** 🟡 Medium  
**Coding Required:** Low (Excel formulas, SQL queries, DAX basics – no software engineering required)  
**Typical Job Titles:** *Junior Data Analyst, Business Intelligence (BI) Analyst, Reporting Specialist, Operations / Marketing Data Analyst*

---

## 🎯 Why Start Here?
Every company collects huge amounts of data (sales, customer behavior, logistics, support tickets), yet most managers struggle to understand what is actually happening.

Companies actively hire career changers for Data Analytics because **understanding real-world business questions and explaining numbers in plain English** is far more valuable than complex statistics. If you already worked in retail, healthcare, finance, logistics, or administration, your domain knowledge gives you a massive head start.

---

## 🗺️ Step-by-Step Learning Roadmap (10–14 Weeks)
*100% free, official Microsoft Learn resources – focused on the exact tools used in real corporate environments.*

### Phase 1: Modern Excel & Data Cleaning (Weeks 1–3)
Forget basic spreadsheets. Real data work starts with cleaning messy files and automating repetitive reports.
* [ ] Master essential data functions (`XLOOKUP`, `INDEX/MATCH`, `SUMIFS`, `COUNTIFS`, Pivot Tables).
* [ ] Learn **Power Query** inside Excel to clean, merge, and transform messy CSV/Excel datasets with a few clicks (no coding required).
* [ ] Understand basic data hygiene (handling duplicates, missing values, date formats, and outliers).
* **Free Official Resource:** 
  * 🎓 **Microsoft Learn – Prepare and Transform Data in Excel / Power Query Modules** *(100% free, practical, no login required to start)*

### Phase 2: Data Modeling & Dashboards With Power BI (Weeks 4–7)
**Microsoft Power BI** is one of the most widely used Business Intelligence tools worldwide – and **Power BI Desktop is 100% free** to download and use on Windows.
* [ ] Understand how to connect multiple data tables (Star Schema basics: Fact tables vs. Dimension tables).
* [ ] Learn basic **DAX** (Data Analysis Expressions) to calculate KPIs (e.g., Year-over-Year growth, moving averages).
* [ ] Design clean, readable executive dashboards (choosing the right chart types without visual clutter).
* **Free Official Resource:** 
  * 🎓 **Microsoft Learn – PL-300: Microsoft Power BI Data Analyst Learning Path** *(Complete, free official curriculum covering data preparation, modeling, and visualization)*

### Phase 3: SQL Fundamentals (Weeks 8–11)
When datasets grow too large for Excel, data lives in relational databases. **SQL** is the universal language to ask databases questions – and its basics are surprisingly easy to learn.
* [ ] Master core SQL queries (`SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`).
* [ ] Learn how to combine data across tables (`INNER JOIN`, `LEFT JOIN`).
* [ ] Practice writing clean, readable queries to answer real business questions.
* **Free Official Resources:** 
  * 🎓 **Microsoft Learn – Query Relational Data with Transact-SQL (T-SQL)** *(100% free, includes interactive browser exercises)*
  * 🎓 **SQLBolt** *(Free, interactive, browser-based SQL practice – great for fast daily drills)*

### Phase 4: Storytelling & AI-Assisted Analysis (Weeks 12–14)
A dashboard nobody understands is useless. The final step is learning how to communicate insights and use modern AI tools safely to speed up your workflow.
* [ ] Learn how to summarize findings for non-technical managers (*"What happened, why did it happen, and what should we do next?"*).
* [ ] Use AI assistants safely to help write complex SQL queries, debug DAX formulas, or brainstorm KPIs – while always verifying the numbers manually.
* **Free Official Resource:** 
  * 🎓 **Microsoft Learn – Explore Data Analytics & AI / Copilot in Power BI Modules** *(100% free)*

## 🛠️ Hands-On Data Portfolio: Build Your Proof of Skills
Hiring managers want to see how you think with data. Build **3 practical projects** using free public datasets (e.g., from Kaggle or government open data portals) and document them on GitHub:

- [ ] **Project 1: The Automated Sales / Operations Cleaner** – Take a messy public CSV dataset, clean and transform it using **Excel Power Query**, and document every cleaning step you took.
- [ ] **Project 2: Interactive Power BI Executive Dashboard** – Build a 2-page interactive report in **Power BI Desktop** (free), take clear screenshots/PDF exports, and write a short summary of the 3 biggest business insights you discovered.
- [ ] **Project 3: Business Questions Answered in SQL** – Write 10 well-commented SQL queries solving real business questions (e.g., top-performing regions, customer churn trends, seasonal peaks) and upload the `.sql` file to GitHub.

## 📄 How to Present Yourself on Your CV
* **Connect Your Past Career to Data:** Highlight that you understand *what the numbers actually mean* in your previous industry (e.g., inventory turnover, patient wait times, customer retention).
* **Show Visual Proof:** Include screenshots of your Power BI dashboards directly in your GitHub portfolio README so recruiters see your work in 5 seconds.
